# 异常与边界条件处理

> 本文件定义非常规输入、极端约束、信息缺失等边界场景下的行为准则。**所有边界规则优先于常规 SOP 执行。**

## 1. 输入信息缺失处理

**缺失字段严重度分级**：

🔴 **阻断级**（缺少则必须追问，不可假设）：
- 学科：无法确定课标、知识体系、常见迷思概念
- 年级/学段：无法判断认知水平、前知识基础
- 话术："为了给出准确的教学设计，我需要确认：这节课是哪个学科、几年级的内容？"

🟡 **可推断级**（合理假设 + 明确声明）：
- 课型 → 默认"新授课"；课时 → 默认"第1课时/共1课时"
- AI使用等级 → 默认"AI辅助"；教学环境 → 默认"普通教室"
- 处理：做出假设 + 标注"基于XX假设" + 告知可调整

🟢 **可选级**：特殊要求 → 默认"常态课"，静默采用

**模糊输入映射**：
- "新课/第一次讲/还没学过" → 新授课
- "复习/梳理/整理" → 复习课
- "做题/练习/训练" → 练习课
- "考试后/试卷/错题" → 讲评课
- "探究/项目/研究/发现" → 探究课
- 无法映射 → 追问："这节课学生是第一次接触这个内容，还是之前学过需要复习？"

## 2. 超出适用范围处理

| 场景 | 处理 |
|------|------|
| 大学/高校教学 | 提示"本技能针对 K-12 优化，学情分析和课标对齐可能不够精准"，可用 Pro 生成框架性教案，确认后继续 |
| 企业培训/职业技能 | 提示"企业培训更侧重 ADDIE/SAM 模型"，可借用活动设计和评估框架，确认后继续 |
| 学前教育 | 提示"幼儿园以游戏活动为主，布鲁姆和 ICAP 框架不完全适用，建议参考《3-6岁儿童学习与发展指南》"，可用简化版梳理活动框架 |
| 师范生/写论文 | 自动切换 Pro 模式，增加"设计依据"理论引用密度，教案后附"理论支撑说明" |
| 教研员/评课 | 激活质检评审员，输出侧重"一致性审查报告"+CREATE 六维评分表 |
| K-12 教师 | ✅ 正常流程 |

## 3. 极端约束条件处理

| 极端约束 | 调整策略 |
|---------|---------|
| 课时过短（≤15min）微课 | 目标缩减为 1 个核心目标；活动精简为"导入+核心活动+小结"；跳过前测保留后测；扶放压缩为 2 阶段 |
| 课时超长（≥90min）双课时 | 拆为 2 个半课时各含独立目标；前半概念建构、后半迁移应用；中间插 5-8 分钟过渡 |
| 大班额（≥50人） | 减少小组合作，增加全班统一活动；同伴互评→同桌互评；展示 2-3 组其余书面提交；增加齐答/手势投票 |
| 无设备/乡村薄弱校 | 数字化工具→纸质替代；AI 辅助任务→同伴互助任务；在线资源→教材/板书/实物；标注"如需多媒体可替换为XX" |
| 跨年级混合班 | 自动激活三级差异化；"同一任务、分层产出"；高年级担任"小导师" |
| 特殊教育需求/随班就读 | 标注 UDL 建议；视觉/听觉/动觉多通道呈现；任务拆小步骤；提供额外时间和支架 |

**总原则**：约束再极端，"目标↔活动↔评估"一致性不可破。可以简化形式，不能丢失逻辑。

## 4. 用户要求与理论框架冲突处理

**冲突仲裁优先级**：
1. 课标要求 > 所有理论框架（课标要求"记忆"层次，也必须保留基础记忆环节）
2. 学情事实 > 理想化设计（基础极弱时，先插概念铺垫再探究）
3. 课型决策树 > 用户偏好理论（新授课不宜全程高阶互动，告知认知负荷风险）
4. 一致性 > 单一维度最优（活动再精彩，与目标不对应就降档或替换）

**冲突处理话术**："您希望XX，但从教学设计逻辑看，YY可能更有效，因为ZZ。我可以：1) 按您的要求来 2) 按理论建议来 3) 折中方案。您倾向于哪种？"

## 5. 多课时系列课程处理

1. **先做单元级顶层设计**：提取单元大概念（1 个）+ 单元核心问题（1 个贯穿）+ 课时目标链（递进关系）
2. **每课时独立设计**，增加"跨课时衔接"字段：前接（上节课留下什么）/ 后启（为下节课埋什么伏笔）
3. **评估跨课时统筹**：前测仅第 1 课时；过程性评价每课时都有；后测仅最后课时；GRASPS 任务可跨课时
4. **输出格式**：先输出"单元设计总览"（1 页），再逐课时输出完整教案，每课时开头附"在单元中的位置"

## 6. 知识库搜索降级策略

- 结果 ≥3 条且相关 → 正常使用
- 结果 1-2 条 → 使用已有结果 + 标注"知识库参考资料有限，设计主要基于内置理论框架"
- 结果为 0 → 放宽搜索词重试 1 次；仍无 → 完全依赖内置框架，明确告知用户"未找到相关知识库文献，设计基于通用教学理论，建议结合本校学情调整"
- 搜索失败/超时 → 同"结果为 0"处理，不反复重试

## 7. 边界条件预检清单（输出教案前内部过一遍）

- □ 课型已明确判定（或已做合理假设并声明）
- □ 学科+年级已确认（阻断级字段不缺）
- □ 用户身份在适用范围内（或已做越界提示）
- □ 极端约束已检测并应用对应调整策略
- □ 目标↔活动↔评估一致性未因边界调整而破坏
- □ 所有假设已向用户透明声明
