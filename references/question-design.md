# ❓ 导学问题设计参考库 —— 分类矩阵 + 单问六特征 + 问题集 + 问题链 + 收放法 + 人机协同

> 来源：《问课：智慧课堂教研指南》（胡小勇主编，广东教育出版社，2026）第 4–5 章蒸馏
> 使用者：🎯目标设计师（定主问题）、🎭活动设计师（问题链与环节问题）、🔍质检评审员（问题质量审查）
> 核心观念：**好问题是一座桥梁，把学生的已知与未知、生活经验与学科思想连起来；问题的质量决定思维的深度。**

---

## 〇、总纲：设计顺序铁律

导学问题不是"想到什么问什么"，而是一条工程流水线，五道工序顺序不可乱：

```
① 矩阵选型（第一节）→ 这节课需要哪几类问题？
② 单问把关（第三节）→ 每个问题本身好不好？
③ 问题集提质（第四节）→ 全部问题合起来精不精、有没有方向？
④ 问题链排序（第五节）→ 问题之间有没有认知梯度？
⑤ 课堂收放（第六节）→ 预设问题怎么变成学生的真问题？
```

配套场景法则：PBL / 大单元 / 跨学科 → 见 `scenario-question-design.md`。

## 一、六维分类矩阵（选型工具）

给每个问题贴标签，不靠感觉靠维度。六条维度**正交**（各管一面，互不影响）：

| 维度 | 两类取值 | 大白话说明 |
|------|---------|-----------|
| ① 来源 | 预设 / 生成 | 教案里写好的 / 课堂上从学生的错误分歧里长出来的 |
| ② 内容 | 内容类 / 方法类 | 问"知识是什么" / 问"怎么学、怎么想" |
| ③ 认知 | 低阶 / 高阶 | 记忆理解应用 / 分析评价创造（⚠ 高阶≠高难度，偏题怪题仍是低阶） |
| ④ 结构 | 良构 / 劣构 | 有标准答案 / 开放、真实、多解或无公认解 |
| ⑤ 理解六面体 | 解释/阐明/应用/洞察/神入/自知 | 学生"懂"的六个侧面：说得清→讲得出→用得上→看得透→换立场→知自己 |
| ⑥ 五何 | 是何/为何/如何/若何/由何 | 是什么→为什么→怎么做→如果…会怎样→从何来/归何处 |

**五何要链式组织成阶梯**，不是五个孤立问题：`是何（事实）→ 为何（因果）→ 如何（方法）→ 若何（假设迁移）→ 由何（溯源归宗）`。

### 良构/劣构的学段配比（硬性参考区间）

| 学段 | 良构占比 | 劣构占比 | 原因 |
|------|---------|---------|------|
| 小学 | 80–90% | 10–20% | 认知支点少，需要脚手架 |
| 初中 | 60–75% | 25–40% | 过渡期 |
| 高中 | 40–55% | 45–60% | 能耐受开放探究 |

- 二者是**连续体、可转化**：劣构问题可拆解为若干递进的良构小问题（搭脚手架），良构问题可加"若换成…呢"变体打开（升阶）。
- ⚠ 失衡即事故：全良构驯化学生"找答案"；全劣构缺支撑、流于空谈。

### 质量红线（每问必守）与五大雷区

红线：服务学科大概念、真实、清晰、基于目标、能激发兴趣并**以问促问**。

| 雷区 | 表现 | 后果 |
|------|------|------|
| 常识题 | 不学也能答 | 无思维增量 |
| 书本直抄 | 答案就在书上某句 | 只练找信息 |
| 体验前置 | 先问感受再学内容 | 情绪共鸣替代概念建构 |
| 过度封闭 | "是不是/对不对" | 思维空间归零 |
| 模糊无路径 | 学生不知道从何想起 | 集体沉默 |

## 二、学科领域差异（选型时按学科调参）

### 人文领域（语文/历史/道法/英语等）：三层问题结构

```
基本问题（学科大观念层）："语言如何塑造身份认同？"（指向大概念，可穿越单元）
单元问题（本单元层）："孔乙己的可悲是谁造成的？"
内容问题（本课文本层）："掌柜、酒客、小伙计、'我'，谁更可悲？为什么？"
```
设计要点：内容问题托底（贴着文本细节），单元问题架桥，基本问题引向意义建构。**忌**：只有内容问题 → 全课停留在"认识一个人"，升不到"理解一种社会现象"。

### 理工领域（数理化生/信息科技等）：老-新-疑难题梯度

```
老问题（已会知识的提取）："圆柱有什么特征？"（贴学生经验起点）
新问题（本课新知的建构）："柴油桶为什么做成圆柱形？"
疑难题（迁移与冲突）："同样铁皮，做圆柱还是长方体容量大？"
```
设计要点：三级梯度从"解题训练"走向"思维育人"；疑难题最好制造**认知冲突**（学生旧想法不够用）。

### 书中案例对照（五步提质效果）

| 课例 | 原问题集病症 | 提质后 |
|------|-------------|--------|
| 《孔乙己》 | 全是"是何/如何"+内容问题（信息提取型） | 补"为何（为何不肯脱长衫）""若何（若活在今天命运如何）"+单元基本问题 → 意义建构型 |
| 《圆柱体积》 | 多停留在"老问题" | 建"老→新→疑难"梯度 → 从算题到理解比值思想 |
| 《星月夜》 | 横向空白、纵向仅低阶 | 补"为何（高饱和蓝黄的视觉心理）""若何（梵高活在今天选什么媒介）" → 从识记到文化判断 |

## 三、单个问题质量六特征（体检工具）

好问题不靠语感，可逐项质检。**每个写进教案的问题都要过这六道关**：

| # | 特征 | 自检问法 | 不合格典型 |
|---|------|---------|-----------|
| 1 | 表述清晰明确 | 学生听一遍就知道要干什么吗？ | 指向模糊、歧义 |
| 2 | 思维目标明确 | 完成这题，学生至少要做到哪个思维动作（解释/论证/比较）？ | 只为"引出下一张PPT" |
| 3 | 引导思维过程 | 问的是"怎么想的"，还是直接问最终结论？ | 只问结论，过程被压缩 |
| 4 | 问题真实 | 情境真实+思维真实（学生真会困惑）？ | 假情境、明知故问 |
| 5 | 留有开放空间 | 有没有思辨余地，还是唯一标准答？ | 过度封闭 |
| 6 | 推动进阶 | 能否把学生推向"为什么/如果…呢"？ | 停在表层不再追问 |

**隐性第七条：等待时间。** 高阶问题提出后留 **10–15 秒** 沉默思考，叫起即答会让高阶问题退化为背诵。

### 体检流程（每问 30 秒）

```
① 先写思维目标：完成这题学生至少达到什么思维表现（用可观察动词）
② 六特征逐条打勾（是/否+理由），定位最弱的 1–2 项
③ 定向修补：模糊→重写；封闭→加"若何/为何"变体；无过程→改"你是怎么想的"；零等待→标注"留10–15秒"
④ 一题缺 3 项以上 → 别硬修，回矩阵重新选型
```

### 单问五误区（ce07，出现即改）

模糊指向不清 ｜ 过于封闭唯一解 ｜ 问题间跳跃无逻辑 ｜ 缺乏层次梯度 ｜ 提问后不留等待时间

## 四、问题集有效性（一节课所有问题合起来）

### 三特征（集合层面的合格线）

1. **统一方向**：全部问题服务于 1 个基本问题/核心任务（逆向设计：先定方向，再倒推需要哪些问）——每个问题都能回溯到方向，答不出"这问为了什么"就删。
2. **认知脚手架**：在学生要"跳级"的地方搭阶梯，前后问题之间跨度不能大。有跃迁必设过渡问。
3. **情境真实有效**：把情境剥掉，问题仍然成立——才是真有效；剥掉情境问题就不成立的，是情境在替问题撑场面。

### 五步提质法（可复用的迭代流程）

```
自由设计 → 对号入座 → 分析诊断 → 优化升级 → 循环迭代
（先写出来） （用五何/布鲁姆 （找横向空白列、 （补维度、升层级、 （直到无空白格）
             给每题贴标签）  纵向断层）      建老-新-疑难梯度）
```

核心纪律：**问题不是越多越好，而是越精越好。** 以核心任务逆向牵引，拒绝随意堆题。

## 五、问题链设计（排序工具）

问题链 = 环环相扣、有认知梯度的问题序列（思维阶梯）。与"一堆散问"的区别：**后一个问题的答案要依靠前一个问题的解决来生成**。

### 五类型 × 课型适配（硬性匹配）

| 链类型 | 形态 | 适配课型 |
|--------|------|---------|
| 平行型 | 多问题并列支撑同一概念 | 新授课（辅）、复习课（主，防碎片化） |
| 收敛型 | 从多方信息收拢到结论 | 讲评课（主，指向"为何错"） |
| 拓展型 | 从一点向开放面发散 | 探究课（主） |
| 提高型 | 认知逐级爬坡 | 新授课（主，起点贴经验）、复习课（辅） |
| 下降型 | 从抽象落到具体应用 | 讲评课（辅，指向"如何改"） |

### 设计纪律（四条）

1. **一节课锁定 1–2 条主线问题链，每条 3–5 问**——超 5 问或同时开 3 条以上，回炉收敛。
2. 后问依赖前问：画出链图，箭头表"依赖/递进"，无平行无关跳问。
3. 控碎片：删冗余碎问；链上高阶问留 10–15 秒等待。
4. 促迁移（六阶）：教师设问 → 教师引问 → 师生互问 → 学生敢问 → 学生会问 → **学生善问**——问题主体逐步从教师移向学生，这是深度学习的标志。

### 防"假生成"三形态（ce08，公开课重灾区）

表演式（答案早已预设，按剧本演）｜点缀式（只有一两个优生代表全班）｜照搬式（直接引资料，没有自己建构）。问题链再漂亮，若答案是预设好的表演，一律不算真链。

## 六、预设到生成：问题收放法

预设问题是"剧本"，收放法让剧本在课堂上长出"真问题"。多轮**放（抛出/开放）—收（回收差异、聚焦矛盾）—再放**：

```
一放一收（挖分歧）：抛预设问题让学生操作，回收时不只判对错，
   专门收"错误、分歧、不完整想法"——板书汇总≥2类典型分歧，作下一轮问题源
二放二收（逼质疑）：把关键矛盾放回小组，从"解答"转向"审题与质疑"
   ——学生提出至少1个"为什么/如果不是呢"，问题主体开始转移
三放三收（上升探究）：把学生的问题上升为全班探究任务，各组验证归纳
   ——学生亲历"从被问到善问"的全程转化
```

**案例（小学"浮力"）**：抛"浮力大小与什么有关"→ 回收"重量/体积/沉浮"三类分歧 → 追问"同体积木块铁块为何一浮一沉"→ 学生生成"是不是和排开的水有关"新假设 → 上升为全班实验任务 → 归纳阿基米德原理。

**纪律**：生成性追问必须始终围绕预设的核心概念/思维任务；学生问题一旦偏离轨道，收回重锚，不强行"假生成"。课时紧时可只做一放一收。

## 七、人机协同设计导学问题（本技能自身的工作方式）

AI 扩展的是问题的**供给能力**，**价值导向与学科边界永远由教师把握**。本技能执行 Step 1.8 时按此闭环工作：

### 五步循环

```
教师构想（定终点：本环节思维目标+学科边界，至少含"年级+目标+禁忌"）
→ AI 发散（拓展问题空间，产出≥3个不同认知层级的方案）
→ 教师三维校准（目标对齐 / 认知挑战 / 课堂可操作，逐题核查）
→ 师生试用反馈
→ 迭代沉淀（入校本资源库）
```

### 提示词"四定"原则（让 AI 出好题的指令模板）

| 定 | 写什么 | 示例 |
|---|--------|------|
| 定目标 | 战略/战术/执行层意图 | "为高一历史《辛亥革命》设计指向'评价历史必然性'的高阶问题" |
| 定背景 | 年级/学生水平/教学进度 | "高一学生，已学完洋务运动，未学民国史" |
| 定结构 | 输出形式 | "输出3个问题，按是何→为何→若何递进，标注认知层级" |
| 定基调 | 语言风格与质量要求 | "开放表述，禁止'是不是/对不对'式封闭提问" |

### 三条边界纪律（违反即返工）

1. 教师自己没想清目标，不给 AI 下空指令（防盲信）。
2. AI 出的题**原样粘贴即成品** = 搬运工，必须三维校准后才可用；若 AI 产出全是良构事实题而教师未补高阶，不得直接用。
3. 问题数量增加 ≠ 思维水平提升——技术解决供给，教师决定价值。

## 八、速查卡：一节课的导学问题设计一页流程

```
1. 定主问题（1个，指向本课深度理解点，贴着大概念）
2. 矩阵选型：按学科（人文三层/理工梯度）+学段（良构劣构配比）定需要哪几类
3. 写初稿：主问题拆成 3–5 问的链（按课型选链类型）
4. 单问体检：六特征+等待时间，逐问打勾修补
5. 集合提质：统一方向+脚手架+真实三特征，五步迭代到无空白
6. 标注入教案：每问带 [五何|良构/劣构|认知层级|等待时间|所在环节] 标签
7. 预案：写好"收放"方案——学生可能的分歧点、追问方向、何时收回重锚
```
