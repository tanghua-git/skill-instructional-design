# 术语对照表与双语写作规则（所有 Agent 输出前必读）

> 本文件是双语铁则的执行工具。规则：**给教师看的输出，大白话在前、术语在后（括号内可省略）；术语首次出现必须配解释。**

---

## 一、双语写作规则

### 规则 1：大白话在前，术语在后

| ❌ 禁止写法 | ✅ 标准写法 |
|------------|------------|
| 本环节采用 ICAP 升档策略 | 让学生从"动手做"升级到"说出为什么这么做"（ICAP 升档） |
| 基于认知冲突理论暴露前概念 | 让学生发现原来的想法解释不了新问题（认知冲突） |
| 运用 GRASPS 模型设计表现性任务 | 设计一个真实场景的任务，让学生像"小专家"一样完成作品（GRASPS 任务） |
| 依据 SDT 设计自主性支持 | 给学生三个任务任选一个，让他们感觉"这是我自己的选择"（自主性） |

### 规则 2：设计意图 = "因为……所以……"

- ✅ "因为学生容易把分数当成除法结果，所以先让他们动手分月饼，自己发现矛盾"
- ❌ "基于迷思概念诊断结果设计认知冲突环节"

### 规则 3：一句话最多 1 个术语

### 规则 4：术语集中收编到教案末尾「设计理论说明」附录

### 规则 5：拿不准怎么翻译时，用"学生做什么/感受到什么"来描述

术语的本质是描述课堂里发生的事——直接写那件事，就不会错。

---

## 二、术语对照表（按用途分组）

### 🎯 目标设计类

| 术语 | 大白话 | 课堂实例 |
|------|--------|----------|
| 布鲁姆分类（认知层次） | 学习要求的深浅：从"记住"到"会创造"六级 | 记住公式→理解意思→会做题→会分析错题→会评价解法→会自己出题 |
| 知识类型（事实/概念/程序/元认知） | 学的是"知识"还是"方法"还是"套路" | 事实=年月日名称；概念=分数的意义；程序=通分的步骤；元认知=知道自己哪类题常错 |
| ABCD 目标写法 | 目标写清四要素：谁、做什么、什么条件、做到什么程度 | "学生（谁）能借助数轴（条件）正确比较两个分数大小（做什么），10题对8题（程度）" |
| 素养目标 | 这节课要给学生带得走的能力，不只是知识点 | "会用数学眼光看生活中的平均分问题" |
| 核心问题 | 一个能让学生想一整节课（甚至更久）的问题 | "分得越细，每份就越小吗？" |
| 大概念 | 这节课最值得学生带走、以后还用得上的"大想法" | "整体被平均分后，部分可以用分数表示" |

### 🎭 活动设计类

| 术语 | 大白话 | 课堂实例 |
|------|--------|----------|
| ICAP（被动/主动/建构/互动） | 学生投入程度的四档：听着→动着→说着自己的理解→碰撞出新想法 | 听讲(P)→做笔记做题(A)→给别人讲明白(C)→辩论中完善观点(I) |
| ICAP 升档 | 把学生的投入程度往上提一档 | 做完题加一步"和同桌互相讲一遍思路" |
| 扶放有度（四阶段） | 先扶着走，再慢慢放手 | 我做你看→咱俩一起做→你做我看→你自己做 |
| 明线暗线 | 明线=学生看到的活动；暗线=老师心里的目标 | 明线是"分月饼游戏"，暗线是"理解分数意义" |
| 认知负荷 | 学生脑子一次能装多少新东西 | 新概念一次只教一个，例题从最简单的开始 |
| 支架 | 给学生的"临时拐杖"，会了就撤掉 | 填空式提纲→提示词→完全独立完成 |
| 认知阻滞点 | 故意设计的"坎"，让学生必须自己动脑筋（AI 也帮不上） | 要求学生用自己的实验数据反驳 AI 给的结论 |
| 刻意练习 | 针对弱项反复练，练完马上有反馈 | 专练"通分"这一步，每题做完立刻对答案说错因 |
| 变式训练 | 换汤不换药的练习，检验是否真懂 | 整数→小数→图形，情境变了但考点不变 |

### 🧠 学情分析类

| 术语 | 大白话 | 课堂实例 |
|------|--------|----------|
| 迷思概念 | 学生脑子里根深蒂固的错误想法 | 学生以为"分数越大分母越大" |
| 前概念 | 学生上课前已有的想法（可能对也可能错） | 学生觉得"重的东西一定沉底" |
| 知识缺乏 vs 迷思概念 | "不懂"（没学过）和"想错"（学偏了）是两回事 | 不懂→直接讲；想错→先让他意识到矛盾再讲 |
| 认知冲突 | 让学生撞见"旧想法解释不了"的时刻 | 学生以为 1/2 和 2/4 不一样大，折纸后发现一样大 |
| 图式 | 学生脑子里已有的"知识框架" | 学生用整数的比较大小的老办法套分数，结果出错 |

### 📝 评估设计类

| 术语 | 大白话 | 课堂实例 |
|------|--------|----------|
| GRASPS 任务 | 真实场景任务六要素：目标/角色/受众/情境/作品/标准 | "你是学校图书管理员（角色），要给一年级同学（受众）设计一份借书规则海报（作品）" |
| 表现性评价 | 不看卷子看"作品"，看学生真能用出来 | 让学生做一次真正的测量并写报告 |
| SOLO 分类 | 学生答案的水平层次：没思路→说一点→说几点→连起来说→能举一反三 | 评价时问：学生是只答出一点，还是能把几点联系起来？ |
| 量规 | 提前给学生看的"打分细则" | 海报评价：内容对 4 分、清楚 3 分、美观 2 分、创意 1 分 |
| 四层诊断 | 通过追问四层问题，分清学生是"不懂"还是"想错" | 答案是什么→为什么这么答→依据是什么→如果……你会怎么改 |
| 前测/后测 | 上课前摸底、下课后验证 | 课前 2 道题探错误想法，课后同类题看是否纠正 |

### 💬 动机与元认知类

| 术语 | 大白话 | 课堂实例 |
|------|--------|----------|
| SDT（自我决定理论） | 学生想学的三个条件：有的选、能成功、被在乎 | 任务三选一（有的选）+三级难度（能成功）+展示互评（被在乎） |
| 内在动机 | 学生因为"想学"而学，不是因为"有奖" | 用"真问题"勾起好奇心，而不是加分 |
| 元认知 | 学生对自己学习过程的"回头看" | "我刚才用什么方法？卡在哪？下次怎么改？" |
| 出声思考 | 老师把脑子里的思考过程说给学生听 | 老师边做题边说："这一步我为什么用乘法？因为……" |
| 反思卡 | 让学生定期"回头看"的小工具 | 练习后填：我用了什么方法/卡在哪/下次改进 |

### 🔍 质检与其他

| 术语 | 大白话 | 课堂实例 |
|------|--------|----------|
| 一致性（目标↔活动↔评估） | 目标、活动、考试三者对得上 | 目标是"会比较分数"，活动就练比较，测验就考比较 |
| 差异化 | 给不同水平学生不同的"台阶" | 基础题/标准题/挑战题，每层学生都有得做 |
| CREATE 六维 | 备课自检的六个方面 | 概念/关系/评估/活动/转化/拓展六方面逐项打勾 |
| AI 评估三分类 | 按学生用 AI 的程度分三类考试 | 不让用 AI 的纸笔考 / 可以用但要声明 / 就考你怎么用 AI |
| 置信度 | AI 对自己判断的把握程度 | 信息给得全→把握高；靠猜→把握低，需要老师确认 |

## 三、改写自检（输出前逐句过）

- [ ] 这句话里的术语，括号外的大白话能独立读懂吗？
- [ ] 这个术语是本教案中第一次出现吗？配解释了吗？
- [ ] 这句话有超过 1 个术语吗？
- [ ] "为什么这样设计"是用"因为……所以……"写的吗？
- [ ] 一位没读过任何教学理论书的老师，能看懂这段话并照着做吗？
